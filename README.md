# CS2-friend-controlling
Забавная программа сделанная для приколов, ты играешь в кс2, твой друг сидит в дискорде и управляет твоей игрой через бота, например достаёт нож в самый неподходящий момент, или вызывает тебе флешку в лицо когда ты стреляешься, и многое другое (Styve - это локальный мем, (фотограф, скринит экран и выводит этот скрин на 3 секунды)


### Список команд

| Команда | Кнопка | Что делает |
|---|---|---|
| `!drop` | 🔫 Drop | Нажимает `G` (сброс оружия) |
| `!knife` | 🔪 Knife | Нажимает `3` (нож) |
| `!hello` | 💬 Hello | Блокирует все клавиши, пишет «привет друзья!» в чат, разблокирует |
| `!reload` | 🔄 Reload | Нажимает `R`, блокирует `1`–`6` и скролл на 3 секунды |
| `!sens` | 🎯 Sens | Плавно двигает курсор в правый верхний угол |
| `!jump` | 🦘 Jump | Нажимает `Space` |
| `!flash` | ⚡ Flash | Белый экран + звук вспышки + приглушение системной громкости |
| `!styve` | 📸 Styve | Звук затвора + скриншот экрана на 3 секунды |

## Установка

### 1. Требования

- **Windows 10/11** (используются WinAPI-вызовы, на Linux/macOS не заработает)
- **Python 3.10+**
- **Права администратора** при запуске (иначе `keyboard` не сможет блокировать клавиши)

### 2. Клонирование

```
git clone https://github.com/твой-ник/discord-pc-controller.git
cd discord-pc-controller
```

### 3. Установка зависимостей

```
pip install -r requirements.txt
```

Если `requirements.txt` нет, поставь вручную:

```
pip install discord.py keyboard pynput numpy pygame mss pillow pycaw comtypes
```

### 4. Настройка бота

Открой `main.py` и заполни две переменные в самом верху:

```python
BOT_TOKEN = "твой_токен_бота"
CHANNEL_ID = 123456789012345678
PREFIX = "!"
```

- `BOT_TOKEN` — токен бота из [Discord Developer Portal](https://discord.com/developers/applications) → твоё приложение → Bot → Reset Token.
- `CHANNEL_ID` — ID канала на сервере, где бот будет писать «напишите в лс боту». Не критично, можно оставить любой.
- `PREFIX` — префикс команд, по умолчанию `!`.

### 5. Включение нужных интентов

В Discord Developer Portal → твоё приложение → **Bot** → включи:

- **Message Content Intent** (обязательно, иначе бот не видит текст сообщений)

Без этого бот не будет реагировать на команды.

### 6. Запуск

```
python main.py
```

При первом запуске Discord может попросить подтвердить, что бот имеет доступ к сообщениям — соглашайся.

## Использование

1. **Напиши боту в ЛС первым.** Discord не даёт ботам инициировать переписку — ты должен открыть профиль бота и написать ему сам. Просто `!start`.
2. Бот пришлёт панель с кнопками.
3. Жми кнопки — команды выполняются на твоём ПК.

То же самое можно делать вручную: `!jump`, `!flash` и т.д. прямо в ЛС.

### Кулдауны

- **Личный кулдаун** у каждой команды свой (например, `!flash` — 15 сек, `!hello` — 40 сек).
- **Общий кулдаун** — 5 секунд на любую команду. Нельзя нажать `!jump` и сразу `!flash`.
- Если нажать кнопку в кд — на ней на 2 секунды появится `КД` или `ОБЩИЙ КД`, остальные кнопки останутся как были.

Все кд считаются отдельно для каждого пользователя.

### Настройка кулдаунов

В коде есть два словаря:

```python
COMMAND_COOLDOWNS = {
    "drop": 10,
    "knife": 8,
    "hello": 40,
    "reload": 10,
    "sens": 10,
    "jump": 5,
    "flash": 15,
    "styve": 40,
}

GLOBAL_COOLDOWN = 5
```

Меняй значения под себя. `0` = без кулдауна.
