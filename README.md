# CS2-friend-controlling

Забавная программа для приколов. Ты играешь в CS2, твой друг сидит в Discord и управляет твоей игрой через бота. Например, достаёт нож в самый неподходящий момент или вызывает флешку в лицо, когда ты стреляешься. И многое другое. Styve это локальный мем: типа фотограф, скринит экран и выводит этот скрин на 3 секунды.

## Список команд

| Команда | Кнопка | Что делает |
|---|---|---|
| `!drop` | 🔫 Drop | Нажимает `G` (сброс оружия) |
| `!knife` | 🔪 Knife | Нажимает `3` (нож) |
| `!hello` | 💬 Hello | Блокирует все клавиши, пишет «привет друзья!» в чат, разблокирует |
| `!reload` | 🔄 Reload | Нажимает `R`, блокирует `1`–`6` и скролл на 3 секунды |
| `!sens` | 🎯 Sens | Плавно двигает курсор в правый верхний угол |
| `!jump` | 🦘 Jump | Нажимает `Space` |
| `!flash` | ⚡ Flash | Белый экран + звук вспышки + приглушение системной громкости |
| `!styve` | 📸 Styve | Звук затвора + скриншот экрана на 3 секунды |

## Установка

### 1. Требования

Нужна Windows 10 или 11, потому что используются WinAPI-вызовы. На Linux и macOS не заработает. Также нужен Python 3.10 или новее. И права администратора при запуске, иначе `keyboard` не сможет блокировать клавиши.

### 2. Клонирование

```
git clone https://github.com/FixOrange/CS2-friend-controlling.git
cd CS2-friend-controlling
```

### 3. Установка зависимостей

```
pip install -r requirements.txt
```

Если `requirements.txt` нет, поставь вручную:

```
pip install discord.py keyboard pynput numpy pygame mss pillow pycaw comtypes
```

### 4. Настройка бота

Открой `main.py` и заполни переменные в самом верху:

```python
BOT_TOKEN = "твой_токен_бота"
CHANNEL_ID = 123456789012345678
PREFIX = "!"
```

`BOT_TOKEN` это токен бота из [Discord Developer Portal](https://discord.com/developers/applications), там заходишь в своё приложение, потом Bot, потом Reset Token. `CHANNEL_ID` это ID канала на сервере, где бот будет писать «напишите в лс боту». Не критично, можно оставить любой. `PREFIX` это префикс команд, по умолчанию `!`.

### 5. Включение нужных интентов

В Discord Developer Portal зайди в своё приложение, потом в Bot, и включи там **Message Content Intent**. Это обязательно, иначе бот не видит текст сообщений и не будет реагировать на команды.

### 6. Запуск

```
python main.py
```

При первом запуске Discord может попросить подтвердить, что бот имеет доступ к сообщениям. Соглашайся.

## Использование

Сначала напиши боту в ЛС первым. Discord не даёт ботам инициировать переписку, так что ты должен открыть профиль бота и написать ему сам. Просто `!start`. Бот пришлёт панель с кнопками. Жми кнопки, и команды будут выполняться на твоём ПК.

То же самое можно делать вручную: `!jump`, `!flash` и так далее прямо в ЛС.

### Кулдауны

У каждой команды свой личный кулдаун. Например, `!flash` это 15 секунд, а `!hello` это 40 секунд. Плюс есть общий кулдаун 5 секунд на любую команду, то есть нельзя нажать `!jump` и сразу `!flash`. Если нажать кнопку в кд, на ней на 2 секунды появится `КД` или `ОБЩИЙ КД`, а остальные кнопки останутся как были. Все кд считаются отдельно для каждого пользователя.

### Настройка кулдаунов

В коде есть два словаря:

```python
COMMAND_COOLDOWNS = {
    "drop": 10,
    "knife": 8,
    "hello": 40,
    "reload": 10,
    "sens": 10,
    "jump": 5,
    "flash": 15,
    "styve": 40,
}

GLOBAL_COOLDOWN = 5
```

Меняй значения под себя. `0` значит без кулдауна.
